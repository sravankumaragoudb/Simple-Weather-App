# Simple Weather Application using HTML, CSS & JavaScript

## Overview of Weather App

A Simple Weather Application made using HTML, CSS & JavaScript with OpenWeatherMap API, along with an MCP (Model Context Protocol) Server and Weather Agent.

### Live Demo
https://prince-shivaram.github.io/Simple-Weather-App/

### Features
- **Frontend App**: Real-time weather lookup by city with dynamic UI updates.
- **MCP Server (`weather-mcp-server`)**: FastMCP server providing `get_weather` and `get_weather_forecast` tools.
- **Weather Agent (`weather-agent2`)**: Intelligent agent retrieving weather insights and generating recommendations.
